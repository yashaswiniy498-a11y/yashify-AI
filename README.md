# Yashify AI

Yashify AI is an AI-powered text summarization application that converts long text into a concise and easy-to-understand summary.

## Features

- Summarizes text using AI
- Simple and user-friendly interface
- Provides quick and concise summaries
- Deployed online using Streamlit Community Cloud

## Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- T5-small model

## How It Works

1. Enter or paste your text into the text box.
2. Click the **Summarise** button.
3. Yashify AI processes the text using an AI summarization model.
4. The generated summary is displayed on the screen.
